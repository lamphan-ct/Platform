## Overview
Job seeker (JS) đã login bấm **Chat** trên adview JOB → thay vì rời adview vào chat room, một **bottom drawer** mở ngay trên adview với thẻ tin đăng, 3 câu hỏi chọn sẵn từ config JOB và ô nhập. JS gửi xong vẫn ở lại adview, thấy SnackBar "Tin nhắn đã được gửi thành công · Xem tin nhắn". A/B test 3 nhóm: Control 40% / T1 30% (checkbox chia sẻ SĐT) / T2 30% (SĐT điền sẵn trong ô nhập).

## Display Condition
```
SHOW drawer khi TẤT CẢ đúng:
  - JS đã login, ad thuộc JOB, không phải ad của chính JS
  - Experiment ats_job_chat_application_inline_drawer = treatment_1 | treatment_2
  - Server gate show_drawer = true (chưa có room, hoặc room chưa có tin nhắn ngoài system message; hoặc JS chuyển sang ad khác của cùng recruiter)
  - JS chưa xác thực SĐT → phải còn trong chat limit (max room, max message/room)
HIDE drawer → flow hiện tại (vào chat room + tin nháp):
  - Chưa login / ad của chính JS / vertical khác
  - Nhóm Control, hoặc experiment lookup lỗi/rỗng (→ Control)
  - show_drawer = false (đã có room có tin nhắn với ad này) → vào thẳng chat room
  - Gate lỗi/timeout, hoặc check chat limit lỗi/timeout
KHÔNG mở drawer + SnackBar "Bạn cần xác thực số điện thoại" (kèm link xác thực SĐT):
  - JS chưa xác thực SĐT và đã vượt chat limit
```

## Interaction Rules
| Trigger | Hành vi |
|---------|---------|
| Tap **Chat** (bottom bar adview) | Kiểm tra Display Condition → mở drawer (T1/T2) / vào chat room / SnackBar vượt limit |
| Drawer mở — T1 | Bàn phím **đóng**; 3 câu đầu được chọn; checkbox SĐT checked (nếu SĐT đã xác thực) |
| Drawer mở — T2 | Ô nhập **focus + bàn phím mở** sẵn; 3 câu đầu được chọn; ô nhập điền sẵn "Liên hệ mình qua SĐT \<phone\>" (nếu SĐT đã xác thực) |
| Tap ô nhập (T1) | Focus, mở bàn phím, drawer đẩy lên trên bàn phím, gạch chân đổi `border-bold` |
| Tap ✕ trên chip đã chọn | Bỏ câu hỏi; chip trở về **đúng vị trí ban đầu** (theo thứ tự config) trong hàng "Hỏi thêm:" |
| Tap chip ở hàng "Hỏi thêm:" | Thêm vào cuối danh sách "Cho mình hỏi:", biến mất khỏi "Hỏi thêm:" |
| Bỏ hết câu đã chọn | Ẩn chữ "Cho mình hỏi:" và khối chip đã chọn |
| Chọn hết câu trong "Hỏi thêm:" | Ẩn cả hàng "Hỏi thêm:" |
| Tap checkbox (T1) | Toggle chia sẻ SĐT |
| Tap **Gửi** (enabled) | Gửi 1 tin theo format §Content Rules → đóng drawer, JS ở lại adview, hiện SnackBar thành công; tạo candidate record cho recruiter |
| Tap **Gửi** (disabled) | Không có action |
| Gửi lỗi (mạng / API) | Drawer **giữ mở**, giữ nguyên nội dung, nút Gửi bật lại; SnackBar lỗi "Gửi tin nhắn không thành công. Vui lòng thử lại." · HTTP 409 (đã gửi) xử lý như **thành công** |
| Tap overlay / vuốt xuống | Đóng drawer, **bỏ nháp**. Mở lại → trạng thái mặc định (3 câu chọn sẵn, checkbox checked / SĐT điền sẵn) |
| Tap "Xem tin nhắn" trên SnackBar | Mở chat room với recruiter của tin này |
| Sau gửi thành công, JS **chưa** xác thực SĐT, chưa nhớ consent | Hiện prompt chia sẻ SĐT của JOB hiện có (không thiết kế mới) |
| Tap Chat lần sau (đã có tin nhắn) | show_drawer = false → vào thẳng chat room |

## Common Rules
```yaml
common-rules:
  loading: DS platform default   # mặc định đã chốt — gồm cả lúc check chat limit / load config chip
  question-source: JOB quick-message config (back-office), giữ đúng thứ tự config; T1 và T2 dùng chung 1 list
  preselect: 3 câu đầu theo thứ tự config; config < 3 câu → chọn hết; config rỗng/lỗi/timeout → không có chip, drawer vẫn mở
  phone: đọc lại phone_verified + SĐT mỗi lần mở drawer
  chip-text: 1 dòng, không xuống dòng, không cắt chữ (white-space nowrap) — tràn thì scroll ngang
  scroll-horizontal: ẩn scrollbar; fade trắng mép phải khi nội dung tràn
  ad-card-text: title + giá mỗi dòng max 1 line, ellipsis
  send-enabled: ≥ 1 câu hỏi được chọn HOẶC ô nhập có text (trim)
```

### Message format (tin gửi đi — 1 tin duy nhất)
```
T1 (checkbox checked):          T1 (unchecked)          T2
Cho mình hỏi:                   Cho mình hỏi:           Cho mình hỏi:
• <câu 1>                       • <câu 1>               • <câu 1>
• <câu 2>                       • <câu 2>               • <câu 2>
<text JS nhập>                  <text JS nhập>          <text trong ô nhập, gồm "Liên hệ mình qua SĐT <phone>" nếu JS giữ>
Gọi lại cho tôi qua SĐT <phone>
```

- Dòng "Cho mình hỏi:" chỉ có khi ≥ 1 câu hỏi (Open Item #5). Không có câu hỏi → chỉ text (+ dòng SĐT ở T1).
- T1 bỏ tick / T2 xoá dòng SĐT → **không gửi SĐT**.
- Thứ tự bullet = thứ tự JS chọn.
