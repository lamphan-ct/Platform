## Overview
Bài test A/B mới cho drawer chat GDS/VEH/PTY. **Control** là drawer T1 (tickbox) đang rollout mặc định (STORY_002 FR-3). **Treatment** chỉ đổi cách trình bày T&C và khung soạn tin: checkbox SĐT nhỏ nằm ngay dưới thẻ tin; "Cho mình hỏi:" + câu đã chọn + ô nhập + nút Gửi gom vào **một khung viền**. Logic chip, format tin, rule gửi giữ nguyên.

---

## Control vs Treatment
| | Control (T1 tickbox — STORY_002 FR-3) | Treatment (new T&C design — STORY-004 FR-3) |
|---|---|---|
| Vị trí checkbox | Dưới hàng "Hỏi thêm:" | **Dưới thẻ tin, trên khung soạn tin** |
| Kiểu checkbox | 24px, label `body-section` `text-secondary` | **16px**, label `body-caption` `text-tertiary` |
| "Cho mình hỏi:" + chip | Nằm tự do trên ô nhập | **Trong khung soạn tin** (viền `border-bold`, bo 16) |
| Ô nhập | Gạch chân, đổi màu khi focus | **Không gạch chân**, nằm trong khung cùng nút Gửi |
| Mở drawer | Bàn phím đóng | **Mở kèm bàn phím, focus ô nhập** |
| Bàn phím mở | — | Checkbox **vẫn hiển thị** (FR-3) |
| Chip, format tin, rule gửi, SĐT | — | Không đổi |

> Control giữ đúng UI hiện tại trên production — spec này chỉ mô tả Treatment.

## Display Condition
```
SHOW drawer (cả Control và Treatment) khi TẤT CẢ đúng:
  - User đã login, ad thuộc GDS / VEH / PTY, không phải ad của chính user
  - Chưa có chat room với seller cho ad này, hoặc room chỉ có system message;
    hoặc user chuyển sang ad khác của cùng seller
  - SĐT chưa xác thực → còn trong chat limit (max room, max message/room)
GROUP: experiment crm_chat_lead_inline_drawer_tnc_design; lookup lỗi/rỗng → Control
HIDE → flow hiện tại (vào chat room + tin nháp):
  - Chưa login / ad của chính user / vertical khác (JOB theo STORY_003)
  - Đã có tin nhắn với ad này → vào thẳng chat room
  - Check chat limit lỗi / timeout
KHÔNG mở drawer + SnackBar "Bạn cần xác thực số điện thoại" + link xác thực:
  - SĐT chưa xác thực và vượt chat limit
Checkbox SĐT: SHOW khi phone_verified = true; HIDE khi false (khung soạn tin dồn lên sát thẻ tin)
PTY: nay áp cho cả user chưa xác thực SĐT; chip lấy từ back-office (khởi tạo = bộ câu hỏi bán / cho thuê hiện tại)
```

## Interaction Rules
| Trigger | Hành vi |
|---|---|
| Tap **Chat** trên adview | Kiểm tra Display Condition → mở drawer kèm bàn phím, focus ô nhập |
| Drawer mở | 3 câu đầu config được chọn (config < 3 → chọn hết); checkbox checked (nếu SĐT đã xác thực) |
| Tap ✕ trên chip đã chọn | Bỏ câu; chip về **đúng vị trí cũ** trong "Hỏi thêm:" |
| Tap chip "Hỏi thêm:" khi đang < 3 câu | Thêm vào cuối "Cho mình hỏi:", biến khỏi "Hỏi thêm:" |
| Tap chip "Hỏi thêm:" khi đã đủ 3 câu | **Không thêm** (tối đa 3 — giới hạn backend). Phản hồi UI: Open Item #1 |
| Bỏ hết câu đã chọn | Ẩn "Cho mình hỏi:" và khối chip; khung soạn tin chỉ còn ô nhập + Gửi |
| "Hỏi thêm:" không còn câu | Ẩn hàng "Hỏi thêm:" |
| Tap checkbox | Toggle chia sẻ SĐT |
| Tap **Gửi** (enabled) | Gửi 1 tin (format §Content Rules) → đóng drawer + bàn phím, user ở lại adview, SnackBar "Tin nhắn đã được gửi thành công · Xem tin nhắn" (3s) |
| Tap **Gửi** (disabled) | Không có action |
| Gửi lỗi (mạng / API) | Drawer giữ mở + giữ nội dung, nút Gửi bật lại, SnackBar "Gửi tin nhắn không thành công. Vui lòng thử lại." · 409 = thành công |
| Tap overlay / vuốt xuống | Đóng drawer, **bỏ nháp**; mở lại về mặc định |
| Tap "Xem tin nhắn" | Mở chat room của tin này |
| Tap Chat lần sau (đã có tin) | Vào thẳng chat room |

## Common Rules
```yaml
common-rules:
  loading: DS platform default        # check chat limit, load config chip, gửi
  question-source: config back-office theo vertical (GDS, VEH, PTY), giữ thứ tự config
  preselect: 3 câu đầu; config < 3 câu → chọn hết; rỗng/lỗi/timeout → không chip, drawer vẫn mở
  max-selected: 3                     # backend Mini CRM giới hạn cứng
  phone: đọc lại phone_verified + SĐT mỗi lần mở drawer
  chip-text: 1 dòng, nowrap, không cắt chữ; tràn → scroll ngang
  selected-chip-rows: 2 chip mỗi hàng; hàng dài hơn khung → cả khối scroll ngang, fade mép phải
  ad-card-text: title + giá mỗi dòng 1 line, ellipsis
  send-enabled: ≥ 1 câu được chọn HOẶC ô nhập có text (trim)
  theme: drawer + adview theo vertical (GDS/VEH vàng, PTY cam); chat room luôn GDS
```
